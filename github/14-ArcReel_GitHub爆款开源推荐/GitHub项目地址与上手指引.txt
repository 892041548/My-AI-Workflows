【官方开源地址】https://github.com/ArcReel/ArcReel
【官方 Releases】https://github.com/ArcReel/ArcReel/releases
【主要开发语言】Python
【GitHub 热度】5367 Stars

================================================================================
📋 一、 硬件与系统前置要求（运行门槛）
================================================================================
1. Linux / macOS / Windows 环境并安装 Docker 及 Docker Compose
2. 至少具备主流大模型与文生图/生视频 API 密钥（如 OpenAI 协议、MiniMax、Midjourney 兼容 API 等）

================================================================================
🚀 二、 保姆级极速上手实操三步走（小白必看）
================================================================================

【第 1 步：拉取代码与配置环境】
克隆官方仓库，进入 deploy 部署目录，复制一份标准环境配置文件：
👉 核心命令：
git clone https://github.com/ArcReel/ArcReel.git && cd ArcReel/deploy && cp .env.example .env

【第 2 步：后台启动 Docker 容器】
一键拉起工作台所有容器服务，密码留空时首次启动会自动生成并在控制台回写：
👉 核心命令：
docker compose up -d

【第 3 步：登录工作台配置模型】
浏览器访问 http://localhost:1241，使用默认账号 admin 登录，在设置页填入文本、图像与视频供应商 API Key 即可。

================================================================================
💡 三、 极客避坑指南与常见问题 FAQ
================================================================================
Q1: 默认暴露 1241 端口，严禁无鉴权直接暴露至公网，远程生产环境务必配置反向代理与 HTTPS。
Q2: 草稿导出功能目前专为中国大陆版剪映深度适配，海外版 CapCut 兼容性尚未完全测试。
