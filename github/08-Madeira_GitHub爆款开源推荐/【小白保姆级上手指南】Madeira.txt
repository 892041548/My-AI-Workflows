🚀 极速上手 3 步走总结
================================================================================
1️⃣ 去官方 Releases 页面下载最新 Madeira.ipa；
2️⃣ 电脑端打开 Sideloadly，连手机将 IPA 拖入，输入 Apple ID 点击 Start 签名安装；
3️⃣ 手机信任证书后，在 Sideloadly 右键点 Enable JIT（或手机端开 JIT），打开 App 即可连 Steam 畅玩！

💡 贴心提醒：免费 Apple ID 签名 7 天有效，到期重签不掉游戏存档与数据！
