📋 一、 硬件与系统前置要求（运行门槛）
================================================================================
1. 设备要求：推荐 iPhone 13 Pro 及以上、iPad Pro / Air（M 系列芯片体验最佳）。
   - 3D 游戏需要强劲的 GPU 和图形算力，A15/A16/A17/A18 或 M 系列芯片能获得高帧率与稳定性。
2. 系统要求：iOS 16 或更高版本（作者官方在 iOS 17 / iOS 18+ 深度开发测试）。
3. 签名要求：个人免费 Apple ID（一次签名可用 7 天）或 开发者证书 / 企业签名服务。
4. 核心权限：需要开启 JIT（即时编译权限，iOS 沙盒运行 x86 转译引擎所必需）。

================================================================================
🚀 二、 保姆级极速上手实操三步走（小白必看）
================================================================================

【第 1 步：获取 IPA 安装包】
👉 前往官方 Releases 页面（https://github.com/willfaust/Madeira/releases），下载最新构建好的 .ipa 安装包到电脑或手机。

【第 2 步：侧载签名安装到 iPhone】
由于苹果 App Store 不允许 JIT 机制，需要使用侧载工具签名安装：
- 推荐方案 A（电脑端最稳妥）：使用电脑打开 Sideloadly（https://sideloadly.io）或 爱思助手 / AltServer，数据线连接手机，导入刚才下载的 Madeira.ipa，输入你的 Apple ID 即可一键签名安装。
- 推荐方案 B（手机端独立续签）：使用 SideStore 或 巨魔商店（TrollStore，若系统支持）。
- 安装完成后，在手机【设置 ➔ 通用 ➔ VPN与设备管理】中，信任你的开发者证书。

【第 3 步：开启 JIT 权限并畅玩】
1. 打开 Madeira App，系统会提示需要启用 JIT 调试权限。
2. 激活方式：
   - 使用 StikDebug / SideStore 自带的 JIT 激活功能；
   - 或使用电脑端 Sideloadly 右键点击已安装的 App 选择 "Enable JIT"；
3. 进入 Madeira 的【Settings】检查：JIT 与 Memory+ 均显示绿色勾选，状态变为【Ready to play】！
4. 连接你的 Steam 账号下载正版游戏，或者导入已有的 Windows 游戏目录，连上蓝牙手柄或开启屏幕触控按键，直接开玩！

================================================================================
💡 三、 极客避坑指南与常见问题 FAQ
================================================================================
Q1: 为什么提示没有 JIT 进不去？
A1: iOS 沙盒限制了动态代码编译，必须通过调试器（如 SideStore/Sideloadly/StikDebug）挂载一次开启 JIT，开启后只要应用不被系统彻底杀死就能一直玩。

Q2: 免费 Apple ID 签名过期怎么办？
A2: 免费个人证书有效期为 7 天。到期后只需用 Sideloadly 重新连电脑点一次签名即可，游戏本体数据和 Steam 云存档均会保留，不会丢失！

Q3: 遇到 Direct3D 缺少 VC++ 运行库报错？
A3: 部分 64 位 Windows 游戏需要 Visual C++ Runtime 支持，请参考官方文档 fetch-vcruntime 指引将 vc_redist 放入应用支持目录。
