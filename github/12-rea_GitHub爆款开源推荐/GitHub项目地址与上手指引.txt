--------------------------------------------------------------------------------
🚀 极速上手 3 步走
--------------------------------------------------------------------------------
1️⃣ 确保本地安装 Node.js 22.19+ 版本（运行 node -v 检查）；
2️⃣ 终端执行一键安装配置向导：
    npx rea-agents setup
    （按提示选择你的 Coding Agent，如 Cursor / Claude Code，自动注册 MCP）；
3️⃣ 重启你的 Agent，输入自然语言即可让 AI 逆向分析应用并复刻对应逻辑！
