================================================================================
📋 一、 硬件与系统前置要求（运行门槛）
================================================================================
1. 操作系统：Windows 10/11、macOS (Apple Silicon / Intel) 或 Linux
2. 源码构建需配备：Rust 1.75+ 环境、CMake 及对应系统编译套件

================================================================================
🚀 二、 保姆级极速上手实操三步走（小白必看）
================================================================================

【第 1 步：下载安装包或克隆源码】
普通用户直接前往 GitHub Releases 或官网下载 dmg/exe 安装包；开发者可克隆仓库。
👉 核心命令：
git clone https://github.com/storytold/artcraft.git && cd artcraft

【第 2 步：桌面端环境初始化与配置】
开发者运行官方提供的 setup 脚本配置本地构建依赖与环境。
👉 核心命令：
./script/artcraft setup

【第 3 步：启动应用并绑定模型】
开发者直接通过脚本启动桌面端，或直接双击安装包，随后在设置中配置所需模型 API 即可开始创作。
👉 核心命令：
./script/artcraft run

================================================================================
💡 三、 极客避坑指南与常见问题 FAQ
================================================================================
Q1: Linux 用户需提前安装 libasound2-dev、libudev-dev 等系统依赖库后方可正常编译。
Q2: 涉及 3D 高斯泼溅 (Gaussian Splats) 和实时网格渲染时，建议开启独立显卡硬件加速以防掉帧。
