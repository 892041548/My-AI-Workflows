## 🛠️ 极速上手说明
1. **克隆本仓库**：
   ```bash
   git clone https://github.com/892041548/My-AI-Workflows.git
   ```
2. **选择目标目录**：进入 `workflows/` 对应期数文件夹。
3. **一键导入**：将 `workflow_config.json` 拖入你的 n8n 或 Dify 面板中即可跑通全流程！
